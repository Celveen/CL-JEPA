# 慢学习器的规划检验（seed 100 保留目标，每形状 50 个，与 S2 流不重叠）

慢学习器：整个 predictor，学习率 1e-4，在 S2 第一段（I×20）或第二段（square×20）的执行转移上训练 300 步（1 步预测损失，encoder 冻结）。

| | I | square | 合计（n=100） |
|---|---:|---:|---:|
| θ0 冻结 | 32% | 38% | 35% |
| 慢学习器 冻结 | 42% | 44% | 43%（16/8，p=0.15） |
| θ0 + AdaJEPA | 50% | 48% | 49% |
| 慢学习器 + AdaJEPA | 46% | 56% | 51%（对 AdaJEPA 16/14，p=0.86） |

按步数预算的累计成功率：

| | I ≤10/15/20/30 | square ≤10/15/20/30 |
|---|---|---|
| θ0 冻结 | 26 / 28 / 30 / 32 | 38 / 38 / 38 / 38 |
| 慢学习器 冻结 | 40 / 42 / 42 / 42 | 44 / 44 / 44 / 44 |
| θ0 + AdaJEPA | 32 / 36 / 44 / 50 | 44 / 46 / 46 / 48 |
| 慢学习器 + AdaJEPA | 42 / 44 / 44 / 46 | 52 / 54 / 54 / 56 |

用错领域（在 T 上用 I 或 square 的慢学习器，冻结）：62% / 62%，θ0 为 78%。
