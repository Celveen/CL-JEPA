# S7b3 三轮长流：七组配对结果

完整表格见 [rounds.md](rounds.md)，图见 [rounds.png](rounds.png)。

## 设置

- 流 S7b3：7 个形状，每个访问 3 次，每段 20 个 episode，共 420 个。前两轮就是 S7b，第三轮是全新的 episode，与 S2/S7 没有重叠。
- 基础模型：bias16k seed0（训练形状 T/L/Z/+）。
- 七组走同一批目标、同一顺序，逐 episode 配对。

| 组 | 说明 |
|---|---|
| AdaJEPA（w0） | 基线 |
| v4（cls4_free） | 两段式无标签路由 |
| v5（cls5_free） | v4 + 有验证的合并 |
| 固定 0.003（fixw4_free） | 每个领域 `slow ← slow + 0.003·Δ`，用 v4 的门控 |
| 真实标签（cls3_oracle） | 按真实形状写入 |
| 真实标签 + 多步损失（cls3_oracle_ms） | 慢学习器用 5 步开环 rollout 损失训练 |
| 真实标签 + 重点回放（cls3_oracle_pr） | 成功 episode 回放 ×2，接触转移加权 |

## 结果（每组 420 个配对 episode）

| 组 | 整体 | 与 AdaJEPA 的差（仅该组成功/仅基线成功，p） | 第 3 次访问 | 没见过形状：第 1 / 2 / 3 次访问 |
|---|---:|---|---:|---|
| AdaJEPA | 71.9% | — | 71.4% | 53.3 / 51.7 / 51.7 |
| v4 | 71.7% | −0.2（18/19，p=1） | 75.0% | 48.3 / 50.0 / 56.7 |
| v5 | 71.7% | 与 v4 逐 episode 完全相同 | 75.0% | 同 v4 |
| 固定 0.003 + 门控 | 74.3% | +2.4（16/6，p=0.052） | 75.0% | 55.0 / 55.0 / 60.0 |
| **真实标签** | **76.2%** | **+4.3（33/15，p=0.013）** | **78.6%** | 53.3 / 60.0 / **70.0** |
| 真实标签 + 多步损失 | 76.0% | +4.0（31/14，p=0.016） | 78.6% | 53.3 / 60.0 / 66.7 |
| 真实标签 + 重点回放 | 74.8% | +2.9（33/21，p=0.13） | 75.7% | 53.3 / 63.3 / 68.3 |

**第 3 次访问没见过的形状（n=60），与 AdaJEPA 相比：**
- 真实标签 +18.3（15/4，p=0.019）
- 多步损失 +15.0（p=0.035）
- 重点回放 +16.7（p=0.021）
- 固定 0.003 +8.3（6/1）
- v4 +5.0

**按形状看：**
- square：AdaJEPA 40/40/35，真实标签 40/55/**75**，v4 35/45/45；
- I：AdaJEPA 40/40/50，真实标签 40/35/55，多步损失 30/45/**70**；
- small_tee：AdaJEPA 80/75/70，真实标签 80/90/80。

## 结论

1. **持续学习第一次得到显著的正结果，而且收益随访问次数累积。**
   - 只要路由正确（真实标签），每个领域一份、用回放训练的慢学习器就比 AdaJEPA 整体高 4.3 个百分点（p=0.013）。
   - 收益几乎全部来自回访没见过的形状：第 1、2、3 次访问分别比 AdaJEPA 高 0、+8、+18 个百分点，而 AdaJEPA 自己保持在 52–53%。
   - 见过的形状上基本不受影响。
   - 这正是"持续学习"应有的形态：见得越多，帮得越多。
2. **无标签路由仍然是瓶颈。**
   - v4 比真实标签低 4.5 个百分点（18/37，p=0.014）。到第 3 次访问它追回了一部分（没见过形状 +5），但远不到真实标签的 +18。
   - 主要损失在 square：第 3 次访问 v4 是 45%，真实标签是 75%。
   - 原因一：v4 的 square 领域只写进了 30 个 square（真实标签是 60 个）。熟悉度门（90 分位）把约 1/3 的 square episode 判为熟悉；按学习器规则写入又要求学习器在该 episode 上比 θ0 更准，第 3 轮 square 只写入了 9 个。
   - 原因二：square 领域里还混进了 8 个 small_tee。
   - I 上 v4 与真实标签持平（55%）。
3. **v5 的合并从未触发，所以 v5 与 v4 逐 episode 完全相同。**
   - 这条流里拆分并不严重：I 只有一个 3 个 episode 的小子领域。它很少再收到新 episode，凑不齐合并判据需要的 3 个交叉验证样本。
   - 所以在这里，拆得多不是问题；问题是写入不足和 small_tee 混进 square。
4. **慢学习器的两种新学法没有超过原来的 1 步预测损失。**
   - 多步损失比真实标签组 −0.2（29/30），重点回放 −1.4（23/29）。
   - 多步损失在 I 第 3 次访问上更好（70% 对 55%），重点回放在没见过形状第 2 次访问上最好（63.3%），但整体都没有差别。
   - 重点回放在见过的形状上略有伤害（第 3 次访问 81.2% 对 85.0%）。
5. **固定 0.003 + 门控整体 +2.4（16/6，p=0.052），接近显著。**
   - 它的慢权重对预测的改变不到 1%，但收益集中在没见过形状的回访（6/1、2/0）。
   - 它不需要回放、开销极小，这是同学之前那个"+2 个点"在严格配对下的复现，值得在另一条流上再验证。

## 下一步建议

1. **改进无标签写入，目标是逼近真实标签的 +4.3 和第 3 次访问的 +18：**
   - 已经读了某个成熟学习器的 episode，只要写入门不拒绝就写入，不再要求"比 θ0 更准"。
   - 熟悉度门槛从 90 分位适当放宽，让更多 square 和 small_tee episode 被巩固。
   - small_tee 混进 square 的问题，可以等合并、拆分都有交叉验证证据后再处理。
2. **换一条流或换种子，复现真实标签组的 +4.3 和"随访问累积"的曲线。** 这是论文主结论，需要第二条流支撑。
3. **固定 0.003 + 门控也一起复现。**
